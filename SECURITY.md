# Security

If you find a vulnerability in Twinvoy, please report it privately through
GitHub's private vulnerability reporting on this repository
(Security → Advisories → Report a vulnerability). Do not open a public issue.

This includes any way to:

- remove or hide the "AI twin" disclosure (display name, frame badge, spoken intro),
- enroll a face without the live person and their consent,
- reach the camera page or media stream without the session token.

Reports are reviewed as quickly as possible. Please include steps to reproduce
and the affected version or commit.
